# PHP Blog Source

从已有博客部署中整理的 PHP 博客源码快照。此仓库只包含程序代码与随代码分发的通用资源，不包含原博客内容或生产环境设置。

## 包含内容

- 博客核心、管理后台和安装程序。
- 默认主题及 HelloWorld 示例插件。
- KirinShiKi 插件（Unlicense）及 MarkdownParse 插件（MIT，详见各自目录的许可证与源文件声明）。插件默认不启用。KirinShiKi 需要另行取得 Handsome 主题，不能直接用于默认主题。

原始作者信息及版权声明已保留。部署包未携带的 `admin/src/` 管理界面源文件和 `tools/build.js`、`tools/package*.json` 构建文件已从上游 v1.2.0 标签补齐；默认主题页脚已恢复上游版本。本仓库是部署代码快照，不是全新开发的博客框架，也不保证与当前上游版本同步。

## 安装

1. 配置支持 PHP 8.0 的 Web 环境，并安装所选数据库对应的 PHP 扩展。可使用 MySQL、PostgreSQL 或 SQLite。
2. 将仓库部署至独立站点目录，使用空数据库；数据库账号只授予该新数据库所需权限。
3. 允许 Web 服务写入 `usr/uploads/`。安装时临时允许生成 `config.inc.php`；也可按安装程序提示手动创建配置文件。
4. 打开 `/install.php`，设置自己的站点地址、数据库连接和管理员账号。安装程序将生成新的配置与初始数据。
5. 安装完成后收紧配置文件及站点目录的写权限。默认主题无需额外设置；附带插件可按需要在后台启用。

生产配置由部署者自行生成，切勿提交到仓库。请勿将原博客的数据库、备份或上传目录复制进公开仓库。

## 隐私与发布范围

本仓库没有导入原博客文章、页面、评论、账号、密码散列、主题配置、媒体上传、数据库备份、访问日志、证书或服务器配置。安装目录中的 `.sql` 文件仅为数据库结构模板，并非生产数据库导出。

Handsome 主题及其配套插件未包含：部署副本中的授权条款禁止公开再分发。AliceStyle、Mo66CnBilifan 等未确认公开再分发许可的组件也未包含。默认主题的外观与原站点不同，原站的个性化设置不会随仓库发布。
